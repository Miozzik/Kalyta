# Kalyta — відкриті задачі

Єдиний список задач проєкту. Зроблене переїжджає в розділ «Стан» README.

## Зараз

- [ ] **Зробити видалення помітним**
      Видалення вже працює — довгий тап по витраті — але його не видно.
      Треба свайп вліво на рядку + скасування дії після видалення.
      Свайп зник, коли список перестав бути `List` заради дизайну;
      повертати через `.swipeActions` або власний жест.

- [ ] **Кастомні категорії**
      Свої назва, іконка й колір; редагування та приховування вбудованих.
      ⚠️ Найдорожчий пункт: `Category` зараз enum усередині `@Model Expense`.
      Свої категорії = окрема `@Model Category` + зв'язок + міграція SwiftData
      для вже збережених витрат. Заразом зачепить `AppEnum` у App Intent —
      параметр категорії стане `AppEntity` із запитом до бази.
